# Personal Footage

Drop your raw clips and images here for the pipeline to index and edit.

## video/

Phone clips, GoPro, anything you shot. Prefer:

- **9:16 vertical** (native portrait mode)
- 1080p or higher
- 3–60 seconds per clip
- Multiple takes of the same action (best for comedy edits)

## images/

Still photos for overlays, B-roll inserts, or thumbnail references.

## Index

```bash
python scripts/index_personal.py personal/video/
```

Low-quality clips (blurry, dark, shaky) are automatically excluded.
